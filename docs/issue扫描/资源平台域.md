# proot 上游 issue 扫描 —— 资源限制/平台/文档域（bxroot 适用性）

## 一、资源限制（内存 / fd / rlimit）
- **#357** Unable to launch desktop environment (Failed to close fd)，41 评论
  痛点：glibc 2.34+ posix_spawn 在旧 Android GKI 内核因 clone3 被禁报 EINVAL，桌面起不来
  适用：【已覆盖】clone3→ENOSYS 回退 src/runtime/clone3_guard.c:8-25；posix_spawn 家族接管 src/proc/proc.c:2449,3149；close 为薄转发 src/runtime/preload.c:6589
  ⭐ 验证缺口：缺 glib g_spawn_async 端到端回归 —— 建议在 guest 内编译 g_spawn_async 最小程序做用例
- **#44** Java >1GB 挂起｜根因=proot 调 personality(ADDR_NO_RANDOMIZE) 破坏 JVM
  适用：【不适用】bxroot 全程不调 personality（src/ 无该符号），缺陷机理不存在
- **#235** virtual memory limits｜想要"限定命令内存"
  适用：【不适用】外部 ulimit -v 即可达成；bxroot 无 /proc/meminfo 虚拟化，需求价值低
- **#196** fcntl OFD 锁失效（sysrepoctl）
  适用：【已覆盖】fcntl 变参原样转发 src/runtime/preload.c:6621-6637，arm64 无 fcntl64 cmd 偏移问题；建议补 python fcntl OFD 锁回归一条
- **#24** 扩展回调携带 fd｜【不适用】bxroot 无 proot 式 extension 回调架构

## 四、平台特异性
- **#79** cpanel jailshell（x86_64）无法运行
  适用：【不适用】bxroot 不支持 x86_64（README.md:266）；但其根因之一 noexec /tmp 迁移出真实缺口（见 ⭐1）
- **#227** Heroku 禁 ptrace 无法跑 proot
  适用：【不适用→bxroot 优势】LD_PRELOAD 无 ptrace，deny-ptrace 环境（Heroku/部分 CI）理论可用；建议补 README 对比卖点并做一次 deny-ptrace 容器验证
- **#290** scanelf Bad system call（seccomp KILL）
  适用：【已覆盖】syscall_guard.c:10-15 即为此设计（ENOSYS 而非 SIGSYS）；可在 RUN_RAW_SYSCALL.sh 加 scanelf 用例
- **#417** kernel 4.19 非 root Android 全挂（execve ENOENT，0 评论）
  适用：【缺口】bxroot 面向 Android 但最低内核版本未声明、4.19 未验证；验证：4.19 设备跑 test/RUN_ALL.sh 子集 + 静态二进制
- **#389** Termux 源码构建失败｜【不适用】上游构建脚本问题，bxroot 走 BUILD_RUNTIME.sh，无对应路径

## ⭐ 高价值缺口汇总（3）
1. stub-loader 硬编码 `/tmp/.bxroot_stub_*`（src/stub-loader/stub-loader.c:139）：/tmp 不可写或 noexec 时静态二进制修补静默失败（open 失败仅返回 NULL），正是上游 #79 noexec 根因的移植版；建议 TMPDIR 回退 + noexec 场景回归
2. glib g_spawn_async 端到端回归（对应 #357）：验证 clone3/posix_spawn 回退链在真实 glib 栈成立
3. 4.19 老内核兼容验证（对应 #417）：为 README 声明最低内核版本提供依据
