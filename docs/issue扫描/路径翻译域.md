# proot 上游 issue 扫描：路径翻译/文件系统语义（430 条 → 24 条相关）

⭐=高价值缺口。代码引用基于 /root/proroot-work/agents/rename-bxroot（只读核查）。

## 一、缺口（按优先级）

**⭐ #407 link2symlink 未拦 getdents64（open, 0评）** l2s 硬链接在 `find . -type l` 下现形。
- bxroot：全 src 无 getdents/getdents64 钩子（grep 证实），l2s 伪装只覆盖 stat/lstat/readlink/scandir → 同病。lstat 报普通文件而 getdents d_type 报 DT_LNK。
- 验证：`bxroot -l <rootfs> sh -c 'touch f; ln f h; find . -type l'`。钩子：getdents64(+getdents32)，在 preload.c scandir(5326) 同族加 d_type 改写。

**⭐ #418 硬链接文件元数据自相矛盾：scandir 报 symlink、lstat 报 regular（open, 0评）** pnpm/Turbopack "Invalid symlink" 构建失败。
- 与 #407 同根：目录项流经 getdents，未经 l2s 伪装层，与 lstat(1631) 的 S_IFREG 伪装冲突。docs/l2s-stat伪装三缺陷分析.md 已记录 cp -a 同族矛盾，#418 是官方用户的真实生产损失 → 补 getdents 钩子一并解决。

**⭐ l2s 相对路径断链（docs/缺陷-l2s相对路径断链-git仓库损坏.md，git 仓库损坏）**
- 本地 430 条按 l2s/link2symlink×relative/cwd 组合检索，**无官方同类 issue**（#28/#95/#132 只谈清理与用法）→ 无上游解法可摘；修复按该文档"方案（推荐）"：l2s_rt_link 入口 getcwd+拼接绝对化，仅动 l2s-runtime.c 入口。
- 验证：文档内最小复现两形态对照 + RUN_L2S_ENTRYPOINTS.sh 回归。

**⭐ #8 unix socket 路径翻译残留：sendto/recvfrom（closed 但官方只做了 bind/connect）**
- bxroot 已覆盖 AF_UNIX bind/connect（preload.c:7167/7208，含抽象命名空间排除与 108 字节上限）；但 sendto/recvmsg/recvfrom 纯转发（7244 注释），sendto(AF_UNIX, SOCK_DGRAM) 的 sun_path 不翻译 → X11/XDG 类 DGRAM socket 缺口。
- 验证：`bxroot <rootfs> 探针 sendto 相对根 socket 路径`，strace 看落点是否进 rootfs。钩子：sendto/recvfrom 入参/出参 sockaddr_un。

**⭐ #64 -w 与 bind 目标一致时 cwd 未归一（closed, 官方 v4.0.1 改设 $PWD）**
- bxroot：launcher 只 setenv BXROOT_* 变量（launcher.c:982-1042），未见 setenv("PWD", workdir)；bash 的 pwd 内建在 "." 与 $PWD 同 inode 时原样回显 $PWD，可能漏宿主路径。
- 验证：`cd /tmp/a && bxroot -r <rootfs> -b /tmp/a:/test -w /test bash -c 'pwd'`。修法：launcher exec 前设 PWD=cfg.workdir。

## 二、已覆盖（含对应代码位置）

- **#89/#151 清理目录越出 /tmp**：PROOT_TMP_DIR 兼容（launcher.c:1021-1042），PROOT_TMP_DIR→BXROOT_TMP_DIR 已接。
- **#438/#384/#385 readlink 顶层 /proc 崩溃**（compare_paths 断言/readlink_proc2 越界）：LD_PRELOAD 无对应断言代码路径，结构上不会崩；`ls -al /proc` 待验证。

- **#131/#28 l2s 中间文件清理/命名**：bxroot 落盘 .l2s.* 与引用计数（l2s-runtime.c:68-94 write_nlink），清理行为待验证。

## 三、不适用（LD_PRELOAD 做不到 / 非翻译问题）

- **#249/#334 tmpfs/ramfs、磁盘镜像模拟**：真实 mount/文件系统语义内核层，LD_PRELOAD 仅能伪造 statfs 视图。
- **#182/#415/#366/#144 compare_paths 断言/readlinkat 空路径崩溃**：proot 自有路径归一化缺陷；bxroot readlinkat 空路径直通内核（合法），无该断言。
- **#104 chroot 伪装**（feature）：钩子已有（preload.c:7476）但记账+重定向是新功能非缺陷。
- **#123 只读 bind**（feature）、**#372 bind 清单从文件加载**（feature）：可做但属新 CLI 能力，低优先级。
- **#15 反向翻译命令、#14 /proc 假条目**（feature）：内部已有 detranslate_binds（preload.c:621），无对外 CLI。
- **#5 隐式绑定冲突**：proot glue rootfs 机制私有，bxroot 无 glue，无此路径。
- **#12 嵌套 proot 的 PATH 搜索**：实为脚本内 PATH 变量笔误（见评论），非翻译缺陷。
